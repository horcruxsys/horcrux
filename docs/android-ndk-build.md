# Android NDK Build Support

This document describes Horcrux's support for building Android JNI (Java Native Interface) libraries using the Android NDK (Native Development Kit).

## Overview

Horcrux provides first-class support for building native C/C++ libraries for Android across all major ABIs (Application Binary Interfaces). The NDK compiler abstraction layer integrates seamlessly with Horcrux's build system to provide:

- **Multi-ABI Builds**: Build for arm64-v8a, armeabi-v7a, x86, and x86_64 from a single configuration
- **Hermetic Builds**: Reproducible builds with isolated toolchains
- **Content-Addressable Caching**: Per-ABI caching for fast incremental builds
- **CMake Integration**: Generate CMake toolchain files for existing projects
- **Modern C++**: Full C++17/C++20/C++23 support with NDK r21+

## Supported ABIs

| ABI | Architecture | Description | Target Devices |
|-----|--------------|-------------|----------------|
| arm64-v8a | 64-bit ARM | ARMv8-A instruction set | Most modern devices (2014+) |
| armeabi-v7a | 32-bit ARM | ARMv7-A with Thumb-2 | Older ARM devices |
| x86 | 32-bit x86 | IA-32 instruction set | Android emulators, rare x86 devices |
| x86_64 | 64-bit x86 | x86-64 instruction set | Modern emulators, rare x86_64 devices |

## Prerequisites

### 1. Install Android NDK

Download and install the Android NDK from:
- [Android Studio SDK Manager](https://developer.android.com/studio/projects/install-ndk)
- [Direct Download](https://developer.android.com/ndk/downloads)

Supported versions: NDK r21 or later (r26+ recommended)

### 2. Set Environment Variables

```bash
# Set NDK path
export ANDROID_NDK_ROOT=/path/to/android-ndk
# or
export ANDROID_NDK_HOME=/path/to/android-ndk

# Verify installation
horcrux-cli doctor android
```

The `doctor` command will detect your NDK installation and display:
- NDK version(s) detected
- Available toolchains
- Supported ABIs

## Quick Start

### Building a JNI Library

Create a simple JNI library:

**hello.cpp:**
```cpp
#include <jni.h>
#include <string>

extern "C" JNIEXPORT jstring JNICALL
Java_com_example_Hello_greeting(JNIEnv* env, jobject /* this */) {
    return env->NewStringUTF("Hello from C++!");
}
```

**Using Horcrux CLI:**
```bash
# Build for single ABI
horcrux-cli build //path/to:hello-jni --abi arm64-v8a

# Build for all ABIs
horcrux-cli build //path/to:hello-jni --all-abis

# Build with specific API level
horcrux-cli build //path/to:hello-jni --abi arm64-v8a --api-level 28
```

### Using the NDK Compiler Directly

**C++ Example:**
```cpp
#include "android_ndk_compiler.h"

using namespace horcrux::core;

// Create compiler for arm64-v8a
AndroidNdk ndk;
ndk.path = "/path/to/ndk";
ndk.version = "26.0.0";

auto compiler = AndroidNdkCompiler::create(ndk, AndroidAbi::Arm64V8a, "21");
if (!compiler) {
    // Handle error
    return;
}

// Compile source file
NdkCompileOptions opts;
opts.optimization_level = "-O2";
opts.cpp_std = "c++17";

auto result = compiler->compile(
    "hello.cpp",
    "hello.o",
    opts
);

// Link to shared library
NdkLinkOptions link_opts;
link_opts.libraries = {"log", "android"};

auto lib_result = compiler->link(
    {"hello.o"},
    "libhello-jni.so",
    link_opts
);
```

## Build Configuration

### Compile Options

```cpp
NdkCompileOptions opts;

// Optimization level
opts.optimization_level = "-O2";  // -O0, -O1, -O2, -O3, -Os

// Debug information
opts.debug_info = true;           // Include debug symbols

// Position independent code
opts.pic = true;                  // Required for shared libraries

// C++ features
opts.cpp_std = "c++17";           // C++ standard version
opts.exceptions = true;            // Enable C++ exceptions
opts.rtti = true;                  // Enable RTTI

// Preprocessor defines
opts.defines = {"NDEBUG", "VERSION=1.0"};

// Include directories
opts.include_dirs = {"/path/to/headers"};

// Additional flags
opts.cxxflags = {"-ffast-math"};
```

### Link Options

```cpp
NdkLinkOptions opts;

// Library type
opts.shared = true;               // Build shared library (.so)

// Libraries to link
opts.libraries = {"log", "android", "OpenSLES"};

// Library search paths
opts.library_dirs = {"/path/to/libs"};

// Strip symbols
opts.strip_symbols = true;        // Reduce library size

// Additional linker flags
opts.ldflags = {"-Wl,--gc-sections"};
```

## CMake Integration

### Generate Toolchain File

Generate a CMake toolchain file for a specific ABI:

```cpp
auto compiler = AndroidNdkCompiler::create(ndk, AndroidAbi::Arm64V8a, "21");
compiler->generate_cmake_toolchain_file("android-arm64-v8a.cmake");
```

**Generated toolchain file:**
```cmake
# CMake Toolchain File for Android NDK
# Generated by Horcrux
# ABI: arm64-v8a
# API Level: 21

set(CMAKE_SYSTEM_NAME Android)
set(CMAKE_SYSTEM_VERSION 21)
set(CMAKE_ANDROID_ARCH_ABI arm64-v8a)
set(CMAKE_ANDROID_NDK "/path/to/ndk")

set(CMAKE_C_COMPILER "/path/to/ndk/.../clang")
set(CMAKE_CXX_COMPILER "/path/to/ndk/.../clang++")
# ... additional settings
```

### Using with CMake

```bash
# Configure with generated toolchain
cmake -S . -B build/arm64-v8a \
    -DCMAKE_TOOLCHAIN_FILE=android-arm64-v8a.cmake \
    -DCMAKE_BUILD_TYPE=Release

# Build
cmake --build build/arm64-v8a
```

## API Levels

Choose the appropriate API level based on your target devices:

| API Level | Android Version | Released | Market Share* |
|-----------|-----------------|----------|---------------|
| 21 | 5.0 Lollipop | 2014 | ~95%+ |
| 23 | 6.0 Marshmallow | 2015 | ~90%+ |
| 26 | 8.0 Oreo | 2017 | ~80%+ |
| 28 | 9.0 Pie | 2018 | ~70%+ |
| 29 | 10.0 | 2019 | ~60%+ |
| 30+ | 11.0+ | 2020+ | ~40%+ |

*Market share is approximate and changes over time

**Recommendation:** Use API level 21 for maximum compatibility, or 23+ for modern features.

## Common Patterns

### Building for All ABIs

```cpp
auto ndks = detect_all_ndk_toolchains(ndk, "21");
for (auto& compiler : *ndks) {
    auto abi = to_string(compiler.get_abi());
    std::cout << "Building for " << abi << std::endl;
    
    // Compile and link
    auto result = compiler.compile_and_link(
        source_files,
        "libmylib-" + abi + ".so"
    );
}
```

### Linking System Libraries

```cpp
NdkLinkOptions opts;

// Common Android libraries
opts.libraries = {
    "log",        // Android logging (__android_log_print)
    "android",    // Native Android APIs
    "OpenSLES",   // Audio
    "EGL",        // Graphics
    "GLESv3",     // OpenGL ES 3.0
    "vulkan",     // Vulkan graphics (API 24+)
    "camera2ndk", // Camera2 NDK (API 24+)
};
```

### Multi-File Projects

```cpp
std::vector<std::filesystem::path> sources = {
    "src/main.cpp",
    "src/utils.cpp",
    "src/jni_bindings.cpp"
};

NdkCompileOptions compile_opts;
compile_opts.include_dirs = {"include"};

NdkLinkOptions link_opts;
link_opts.libraries = {"log"};

auto result = compiler.compile_and_link(
    sources,
    "libmyapp.so",
    compile_opts,
    link_opts
);
```

## Performance Optimization

### Compiler Flags

```cpp
// Release build
opts.optimization_level = "-O3";      // Maximum optimization
opts.debug_info = false;              // No debug symbols
opts.cxxflags = {
    "-ffast-math",                    // Fast floating point
    "-fno-exceptions",                // Disable exceptions (if not needed)
    "-fno-rtti",                      // Disable RTTI (if not needed)
    "-fvisibility=hidden",            // Hide symbols by default
};

// Size optimization
opts.optimization_level = "-Os";      // Optimize for size
link_opts.strip_symbols = true;       // Strip symbols
link_opts.ldflags = {
    "-Wl,--gc-sections",              // Remove unused sections
    "-Wl,-s",                         // Strip all symbols
};
```

### ABI Selection

- **arm64-v8a**: Best performance on modern devices
- **armeabi-v7a**: Smaller binary size, wider compatibility
- **x86/x86_64**: Only for emulators in most cases

**Strategy:** Ship arm64-v8a and armeabi-v7a for most apps.

## Troubleshooting

### NDK Not Found

**Symptom:**
```
Error: Android NDK not found
```

**Solution:**
1. Install NDK via Android Studio SDK Manager
2. Set `ANDROID_NDK_ROOT` environment variable
3. Verify with `horcrux-cli doctor android`

### Clang Not Found

**Symptom:**
```
Error: Clang compiler not found
```

**Solution:**
- Ensure NDK r21 or later is installed
- Check that `$NDK_ROOT/toolchains/llvm/prebuilt/` exists
- Reinstall NDK if corrupted

### Compilation Errors

**Missing JNI headers:**
```cpp
// Make sure to use NDK's JNI headers
#include <jni.h>  // Provided by NDK sysroot
```

**Undefined symbols:**
```cpp
// Link with required libraries
link_opts.libraries = {"log"};  // For __android_log_print
```

### Library Size

Large libraries can be reduced by:
1. Using `-Os` optimization
2. Stripping symbols
3. Enabling link-time optimization (LTO)
4. Removing unused ABIs

```bash
# Check library size
ls -lh libmyapp.so

# Analyze symbols
nm -C libmyapp.so | less

# Strip manually
llvm-strip libmyapp.so
```

## Best Practices

1. **Use API level 21+** for maximum compatibility
2. **Build for arm64-v8a and armeabi-v7a** for production
3. **Enable optimization** in release builds
4. **Strip symbols** to reduce size
5. **Test on real devices** not just emulators
6. **Use content-addressable caching** for faster builds
7. **Version your NDK** in build configuration
